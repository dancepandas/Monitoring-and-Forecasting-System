

## 查询设备实时视频


**接口地址**:`/aiflow2/deviceCamera/cameraInfo/{deviceCode}`


**请求方式**:`GET`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`


**接口描述**:


**请求参数**:


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|deviceCode|设备码|path|true|string||


**响应状态**:


| 状态码 | 说明 | schema |
| -------- | -------- | ----- | 
|200|OK|ResultModel«List«CameraVo»»|
|401|Unauthorized||
|403|Forbidden||
|404|Not Found||


**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- | 
|code||integer(int32)|integer(int32)|
|data||array|CameraVo|
|&emsp;&emsp;cameraId|摄像头ID|integer(int32)||
|&emsp;&emsp;cameraIndex|摄像头序号|integer(int32)||
|&emsp;&emsp;liveAddress|播放地址|string||
|&emsp;&emsp;name|摄像头名称|string||
|&emsp;&emsp;programState|摄像头状态: 0-离线 1-在线 2-未知|integer(int32)||
|msg||string||
|pageInfo||分页信息|分页信息|
|&emsp;&emsp;current|当前页码号|integer(int64)||
|&emsp;&emsp;pages|共有多少页|integer(int64)||
|&emsp;&emsp;size|每页条数|integer(int64)||
|&emsp;&emsp;total|总条数|integer(int64)||


**响应示例**:
```javascript
{
	"code": 0,
	"data": [
		{
			"cameraId": 0,
			"cameraIndex": 0,
			"liveAddress": "",
			"name": "",
			"programState": 0
		}
	],
	"msg": "",
	"pageInfo": {
		"current": 0,
		"pages": 0,
		"size": 0,
		"total": 0
	}
}
```
