

## 获取站点实时测流信息


**接口地址**:`/aiflow2/client/monitorWater/realTimeInfo/{stationCode}`


**请求方式**:`GET`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`


**接口描述**:


**请求参数**:


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|stationCode|流量检测站点对象ID|path|true|string||


**响应状态**:


| 状态码 | 说明 | schema |
| -------- | -------- | ----- | 
|200|OK|ResultModel«RealTimeInfoVO»|
|401|Unauthorized||
|403|Forbidden||
|404|Not Found||
