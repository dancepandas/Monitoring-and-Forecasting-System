# 前端 UI 改造需求文档

**文档类型：** UI/UX 需求文档  
**面向对象：** UI 设计师  
**项目：** 郴州流域水文监测与预警指挥平台  
**日期：** 2026-07-13  
**当前分支：** `feature/3d-terrain-model`

---

## 1. 项目背景与目标

### 1.1 系统定位
水文监测与防洪预警指挥平台，核心用户为值班人员、调度人员、管理人员。界面需要在长时间盯屏场景下保持清晰、低疲劳、信息层级明确。

### 1.2 当前问题
- 界面风格不统一，部分组件带有厚重边框和阴影
- 中英文混杂，部分标题、标签仍为英文
- 站点编码直接暴露给用户（如 `STATION // 00230`）
- 信息密度不均，重点数据不够突出
- 报告预览像老旧的弹窗，不像 Word 阅读器
- 3D 地形图范围过大、站点过密，已改为视频监控墙

### 1.3 改造目标
- 统一为**暗色驾驶舱/指挥舱风格**
- 减少边框，使用玻璃态/半透明面板
- 全中文界面，前端不再显示站点编码
- 突出重点数据，弱化辅助信息
- 报告预览接近本地 Word 阅读体验
- 视频监控墙专业、清晰、有状态反馈

## 2. 整体设计方向

### 2.1 视觉关键词
暗色、驾驶舱、玻璃态、少边框、大圆角、胶囊按钮、终端感、专业、冷静。

### 2.2 色彩方向
- **背景**：深色地图/深色底，面板使用半透明深色
- **主色**：柔和的科技蓝（用于重点、按钮、高亮）
- **状态色**：
  - 红色预警：危险
  - 橙色预警：严重
  - 黄色预警：注意
  - 蓝色预警：提示
  - 绿色/青色：正常、在线
  - 灰色：离线、未知
- **文字**：浅色文字在深色底上，层级通过透明度区分

### 2.3 字体方向
- 标题：清晰、有力量感，可适度使用等宽/科技字体
- 正文：易读的无衬线中文字体
- 数据：等宽或tabular数字字体，方便对齐

### 2.4 面板风格
- 半透明玻璃态背景（`rgba` + `backdrop-filter: blur`）
- 细描边或无边框
- 大圆角（12px ~ 20px）
- 轻微内阴影或外发光，营造层级
- 避免厚重 box-shadow 和渐变边框

## 3. 全局设计规范

### 3.1 颜色 Token（参考 / 可调整）
当前文件：`web/src/styles/tokens.css`

建议保留的语义：
- `--bg`：页面背景
- `--bg-2`：卡片/面板背景
- `--bg-3`：悬停/次级背景
- `--primary`：主按钮、高亮
- `--primary-600`：主色 hover
- `--ink`：主文字
- `--ink-2`：次级文字
- `--muted`：辅助/禁用文字
- `--line`：分割线/描边
- `--radius-xl` / `--radius-lg`：圆角
- `--danger` / `--orange` / `--warn` / `--info` / `--ok`：状态色

UI 设计师可以重新赋值这些 token，但建议保留语义命名，方便开发同步。

### 3.2 字体规范
- 页面标题：18px ~ 24px，粗体
- 面板标题：14px ~ 16px，中等字重
- 正文/数据：12px ~ 14px
- 辅助说明：11px ~ 12px，透明度 60% ~ 70%
- 建议中文字体：PingFang SC、Microsoft YaHei、Noto Sans SC

### 3.3 间距规范
- 页面内边距：16px ~ 24px
- 卡片间隙：10px ~ 16px
- 卡片内边距：16px ~ 20px
- 列表项间距：8px ~ 12px

### 3.4 圆角规范
- 大面板：16px ~ 20px
- 卡片：12px ~ 16px
- 按钮/标签：999px（胶囊）或 8px ~ 10px
- 输入框：8px

### 3.5 按钮规范
- 主按钮：填充主色，白色文字，圆角胶囊
- 次按钮：透明底 + 细描边，浅色文字
- 危险按钮：红色填充或红色描边
- 小按钮：高度 28px ~ 32px

### 3.6 表格规范
- 表头：背景与正文区分，可加粗
- 行高：紧凑但不拥挤
- 悬停行：轻微高亮
- 避免粗边框，使用细线或仅底部线

### 3.7 滚动条
- 全局滚动条隐藏（`scrollbar-width: none`）
- 内容区域仍需支持滚动
- 可考虑 hover 时显示极细滚动条作为反馈

## 4. 页面级改造要求

### 4.1 OverviewPage（总览页）

**当前状态：**
- 中间区域已改为 2×2 视频监控墙
- 左侧/右侧/底部为信息卡片
- 使用 CSS Grid 布局（`top / left / center / right / bottom`）
- 右侧预警告警面板与左侧卡片对齐

**改造目标：**
- 视频监控墙专业、清晰、有强烈的状态反馈
- 四周边界卡片统一风格
- 整体暗色驾驶舱感

**具体元素：**
- **视频格子（video-cell）**：
  - 圆角 12px ~ 16px
  - 顶部站点名标签，去掉编码
  - 视频画面占满，16:9 或自适应
  - 离线/加载中：深色占位 + 图标 + 文字提示
  - Hover：轻微放大或边框高亮
  - 点击：可打开站点详情（保留交互）
- **四周卡片**：
  - 统一玻璃态面板
  - 标题中文，字号 14px ~ 16px
  - 内容区域支持滚动
- **顶部标题栏**：终端式标题，可带当前时间/系统状态

### 4.2 ReportsPage（报告归档页）

**当前状态：**
- 列表页展示日报类型和归档统计
- 点击后打开「文档阅读器」弹窗
- 弹窗：顶部工具栏 + 右侧 Word 渲染区
- 底色 `rgb(239, 246, 255)`

**改造目标：**
- 列表页简洁、卡片化
- 阅读器弹窗更像专业文档阅读器
- Word 纸张效果干净、有层次

**具体元素：**
- **列表页**：
  - 日报卡片：标题、日期、摘要、生成按钮
  - 统计卡片：类型、份数
  - 卡片圆角、hover 态
- **阅读器弹窗**：
  - 顶部工具栏：返回/下载/关闭，图标化
  - 标题区域：报告名称、生成时间、文件信息
  - 文档渲染区：浅蓝底色，白色纸张居中
  - 纸张：A4 比例感，轻微阴影，上下翻页/滚动自然
  - 加载态：优雅的 spinner
  - 空状态：插画/图标 + 文字

## 5. 组件级规范

### 5.1 Topbar（页面标题栏）
- 左侧：大标题 + 灰色副标题
- 标题字体可略大、有科技感
- 右侧：可操作按钮（如生成报告、刷新）

### 5.2 TabBar（顶部导航）
- 当前项高亮
- 未选中项降低透明度
- 图标 + 文字，圆角胶囊形状

### 5.3 Panel（通用卡片）
- 玻璃态背景
- 头部：标题 + 右侧操作/说明
- 内容区：内边距 16px ~ 20px
- 圆角 12px ~ 16px
- 细描边或无边框

### 5.4 StationDrawer（站点详情抽屉）
- 从右侧滑出
- 顶部：站点名（无编码）
- 内容：水位、流量、状态、详情
- 数据用大字号 + 单位
- 趋势图区域

### 5.5 Badge/Tag
- 胶囊形状
- 状态色填充或描边
- 小号字体

### 5.6 Button
- 主按钮：填充色 + 圆角胶囊
- 次按钮：透明底 + 描边
- 图标按钮：圆形或圆角方形

### 5.7 Table
- 表头背景区分
- 行 hover 高亮
- 数据右对齐（数字）
- 避免粗边框

## 6. 约束与禁忌

### 6.1 必须遵守
- **前端不显示站点编码**，只显示站点名称
  - 郴州、郴州-坳上、郴州-鸡嘴桥下游、郴州-燕泉河
- **全中文界面**，按钮、标题、标签、提示均为中文
- **暗色主题优先**，新增组件必须适配暗色背景
- **滚动条默认隐藏**，但多内容区域必须可滚动
- **报告预览保持 Word 阅读器风格**，不要厚重边框

### 6.2 不建议
- 死亡大边框、厚重阴影
- 过多渐变背景
- 中英混杂标签
- 站点编码直接展示
- 过于活泼/卡通化的图标

- 如果改动组件的 props、事件、slot 结构，需要同步调整功能逻辑
